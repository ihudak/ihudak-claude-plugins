## Context

The v2.3.0 whole-branch review found documentation that still says mechanical agents "inherit the
session's model" — stale against the uniform routing doctrine v2.3.0 shipped (mechanical steps are
pinned to the §2.1 Sonnet chain by their callers; synthesis/review run on Opus; nothing relies on
session inheritance). "Inherits the session's model" describes each agent's frontmatter *default*
(no `model:` pin) — technically true, but misleading now that callers pin per the policy.

## Goal

Reframe the doc surfaces to point at the model-routing policy rather than claim session inheritance,
without restating a specific tier per agent (which would drift and needs per-agent determination —
`doc-planner` is Opus synthesis, `/release-notes` hasn't adopted routing, etc.).
