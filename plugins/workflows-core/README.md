# workflows-core

Shared foundation for the `dev-workflows` plugin family: the addressing grammar and specs-repo git entry points, phase handoff, model routing, escalation and finding-triage rules, cost/feedback/follow-up emission, and the reference loader skill that lets a dependent plugin read them. It also carries the family-meta utility commands and `/frames`, the design-frame-set indexer.

This is the extraction target for that shared foundation, created as an empty, gate-green skeleton ahead of the content later tasks in the marketplace split move into it. At this point it ships 0 slash commands, 0 agents, and 0 reference files.

See [the documentation index](docs/README.md) for the full command, agent, and reference inventory as it grows.
