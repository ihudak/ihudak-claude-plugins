The B3 whole-branch review shipped v2.2.0 clean (0 Critical / 0 Important) with two

## Goals

1. Remove wording in `epics.md` that asserts the Obsidian vault as the *only* output
   home, now that `/epics` writes to a derived `epic-drafts/<jira_key>/` dir beside the
   imported hierarchy when `$VAULT_PATH` is unset.

   canonical `jira_key` used everywhere else in the file.
3. Refresh the marketplace `README.md` command list from the pre-B1 `/impl:*` names to
   the current 9-command surface.
