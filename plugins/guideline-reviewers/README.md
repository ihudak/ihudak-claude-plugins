# guideline-reviewers

Two standalone review commands, and the guidance they review against: an OpenAPI specification against bundled REST API and IAM permission-naming guidance, and application code or UI against bundled public design-system and accessibility standards. Neither command consumes a workflow artefact or produces one.

This plugin currently ships 0 slash commands — the manifest, licence, and documentation shell are registered first so the repo can carry a second plugin before any content moves into it. The commands and their bundled reference guidance land in a later step.

See [the documentation index](docs/README.md) for what exists so far.
