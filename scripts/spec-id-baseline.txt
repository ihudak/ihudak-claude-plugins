# "Jira-safe requirement IDs" change (2026-08-18). These identifiers are
# deliberately OUTSIDE the [PREFIX#N] grammar and must stay byte-identical:
# a change here means a global replace reached the spec/design namespace.
#
# Scan root: plugins/ CLAUDE.md   (all commands below are run from the repository root)
#
# CHANGELOG.md is EXCLUDED, for the same reason the grammar gate excludes it:
# it is history, and a changelog entry quoting [Uxx] is prose *about* the
# namespace, not a use of it. Counting it desensitised the tripwire -- any
# release note mentioning a spec ID shifted the numbers, training the reader to
# regenerate the baseline instead of investigating. It also destroyed the
# cross-edition comparability that an earlier version of this header wrongly
# claimed as the reason to include it: the three editions keep different
# changelogs, so counting them made the numbers diverge. With CHANGELOG.md
# excluded all three editions produce this file's numbers exactly, so drift in
# one edition is now visible as a difference from the other two.
#

#   ( grep '^#' scripts/spec-id-baseline.txt; \

#       --include='*.md' --exclude='CHANGELOG.md' plugins/ CLAUDE.md 2>/dev/null | sort | uniq -c \
