to-spec,to-tickets,research,domain-modeling,wayfinder,diagnosing-bugs,

## Method note — what "recent" means here

Unlike the `superpowers` audit (680 commits, only 273 in 120 days — a mature repo with a
churn window), `mattpocock-skills` has **316 commits total and no history before 120 days
ago** — the whole repo is inside the churn window given in the brief. So "what changed
recently" and "what the skill currently says" are close to the same question here; where a
file is genuinely old-and-stable (e.g. `codebase-design`, `domain-modeling`, `diagnosing-bugs`
— all essentially unchanged since their initial batch-add commit `221ffca`), that's called out
explicitly rather than implying it was just edited.
